# Release 2026_028 (2026-07-13)

This release is the final update containing upstream changes for our NixOS 25.11 platform.
Going forward, security vulnerabilities for 25.11 will only be patched on a case-by-case basis for severe issues.
We strongly recommend upgrading to the 26.05 platform as soon as possible.


## Impact

None


## NixOS 25.11 platform

- Pull upstream NixOS changes, security fixes, and package updates:
    - docker_29: 29.5.3 -> 29.6.0
    - firefox: 152.0.3 -> 152.0.4
